ทำครั้งเดียว จากนั้นใช้งานได้ตลอด
ขั้นตอนที่ 1 — ติดตั้ง dependencies
เปิด Command Prompt แล้วรัน:
pip install fastapi uvicorn openai
ขั้นตอนที่ 2 — รับ API Key ฟรี
สมัครที่ https://opentyphoon.ai → API Keys → Create
copy key ที่ได้ (ขึ้นต้นด้วย sk-)
ขั้นตอนที่ 3 — รัน Backend
เปิด Command Prompt แล้วรัน:
set TYPHOON_API_KEY=sk-xxxx
python D:\TOR_AI\Program\backend.py
จะเห็น: 🚀 TOR AI Backend รันที่ http://localhost:8000
ขั้นตอนที่ 4 — ทดสอบ
